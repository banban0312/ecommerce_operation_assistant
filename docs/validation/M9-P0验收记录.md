# M9 P0 交付验收记录

## 使用方式

在 `code` 仓库根目录执行：

```powershell
.\scripts\init-env.ps1
docker compose up --build -d --wait --wait-timeout 180
.\scripts\p0-regression.ps1 -ReportPath .\reports\m9-p0-regression.json
```

需要验证登录后的页面时，使用管理员凭据调用脚本：

```powershell
$credential = Get-Credential -Message '输入管理员账号和密码'
.\scripts\p0-regression.ps1 -Credential $credential -ReportPath .\reports\m9-p0-regression.json
```

凭据只存在于当前 PowerShell 进程，不会写入报告或仓库。脚本覆盖 API/Web 健康检查、匿名访问保护、管理员登录、运营大盘、商品工作台、模型配置、导入中心、退出登录，以及数据库迁移和 Worker 往返任务。

## 交付边界

- Compose 负责 MySQL、Redis、迁移、API、Worker 和 Web 六个服务；数据库、Redis 和上传卷使用命名卷持久化。
- `migrate` 成功退出是正常状态；API、Worker 和 Web 应保持健康运行。
- `scripts/p0-regression.ps1` 是可重复的本机回归入口；真实供应商生成、Chrome/Edge 操作和业务流程仍需在隔离演示数据上人工确认。
- 报告文件建议放在被 Git 忽略的 `reports/` 目录，不提交管理员凭据或真实业务数据。
