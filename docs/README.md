## 文档维护约定

- `README.md` 是安装、运行和日常操作的入口；新机器部署不依赖本机缓存、IDE 配置、`.env` 或容器数据卷。
- PRD 与 Spec 是有版本日期的设计基线。代码实现发生变化时，先更新实现状态说明；有意修改产品或架构决策时，再修订对应基线并记录版本。
- 验收报告、测试输出和真实业务数据不放进版本库；个人密钥只留在本机 `.env` 或受控配置中。
